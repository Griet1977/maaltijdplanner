# Maaltijdplanner definitieve V1

Deze statische GitHub Pages-versie bevat:

- duidelijke scheiding tussen geselecteerde en ingeplande suggesties;
- vrije keuze van dag en maaltijd bij het inplannen;
- wijzigen of losmaken van een bestaande planning;
- conflictcontrole wanneer een maaltijd al ingevuld is;
- scherm Thuis eten met L en A onder elkaar per dag;
- groene aanduiding voor thuis eten;
- gebruikers activeren en deactiveren met behoud van gegevens;
- weekoverzicht en gerechtenhistoriek;
- lokale opslag in de browser.

## Publiceren

Upload `index.html`, `styles.css`, `app.js`, `.nojekyll` en dit bestand naar de hoofdmap van de GitHub-repository. GitHub Pages moet ingesteld staan op `main` en `/(root)`.

## Belangrijk

Dit is een gedeeld-toestelprototype. Gegevens worden in `localStorage` opgeslagen en synchroniseren nog niet tussen verschillende toestellen.
