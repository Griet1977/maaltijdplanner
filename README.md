# Aan tafel - Maaltijdplanner V3

Deze versie bouwt qua layout opnieuw verder op het allereerste wireframe.

## Layoutcorrecties
- Rustig wit weekoverzicht met compacte dagkaarten.
- Geen grote groene vinkblokken in de planning.
- Aanwezigheid gebruikt kleine ronde bolletjes: wit indien afwezig, groen met klein vinkje indien aanwezig.
- De oorspronkelijke zwart-wit, minimalistische stijl blijft behouden.

## Functionele flow
- Gebruikers toevoegen, activeren en tijdelijk deactiveren.
- Suggesties selecteren zoals in de eerste versie en per suggestie een dag kiezen.
- Vanuit een lege dag rechtstreeks naar de suggesties voor die dag.
- Rechtstreeks plannen of optioneel twijfelen en stemmen.
- Lokale opslag via localStorage.

## Publiceren
Upload alle losse bestanden naar de hoofdmap van je GitHub-repository. Als GitHub Pages al actief is, volstaat een nieuwe commit.
