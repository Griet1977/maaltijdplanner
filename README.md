# Aan tafel V6.2 stabiele herbouw

Deze versie gebruikt Firebase compat-scripts in plaats van ES-module imports en toont een zichtbare foutmelding als Firebase niet laadt.

1. Upload `index.html`, `styles.css`, `firebase-config.js` en `app.js` naar de root van GitHub.
2. Vervang oude `cloud.js`; die is niet meer nodig en mag verwijderd worden.
3. Publiceer de inhoud van `firestore.rules` via Firebase > Firestore > Rules.
4. Vernieuw de GitHub Pages-site met Ctrl+F5.
5. Registreer Griet als eerste account.
