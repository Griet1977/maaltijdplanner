# Aan tafel - definitieve V1 met stemmen

Upload `index.html`, `styles.css`, `app.js` en `.nojekyll` naar de root van de GitHub-repository. GitHub Pages: branch `main`, map `/(root)`.

## Nieuw
- compacte gerechtendropdown én inklapbare volledige lijst;
- bij planningsconflict: vervangen of beide gerechten in stemming opnemen;
- één stem per actieve gebruiker;
- unieke winnaar wordt automatisch op de gekozen dag en maaltijd ingepland;
- bij ex aequo beslist de beheerder;
- L en A onder elkaar, groen voor thuis;
- gebruikers activeren/deactiveren;
- planning wijzigen of losmaken.

## Opslag
Deze versie gebruikt lokale browseropslag. Verschillende gsm-toestellen synchroniseren nog niet. Daarvoor is in een volgende technische stap een gedeelde online databank plus gebruikersaanmelding nodig.
