# Aan tafel - Maaltijdplanner V2

Aangepast prototype voor GitHub Pages.

## Nieuwe flow
- De gebruikerskeuze toont gewoon de naam, zonder “Ik ben”.
- Gebruikers kunnen toegevoegd en per week geactiveerd of gedeactiveerd worden.
- Het aanwezigheidsoverzicht gebruikt kleine witte bolletjes die groen worden met een vinkje.
- Suggesties werken opnieuw als een eenvoudige selectielijst per gebruiker.
- Elke geselecteerde suggestie krijgt een weekdag. Daardoor verschijnt ze alleen bij die dag.
- Vanuit de dagsuggesties kun je rechtstreeks plannen of optioneel “Twijfel” kiezen.
- Vanaf twee twijfelgerechten kan een stemming worden gestart.

## Publiceren
1. Pak de zip uit.
2. Upload alle losse bestanden naar de hoofdmap van een GitHub-repository.
3. Ga naar Settings > Pages.
4. Kies Deploy from a branch, branch main en /(root).

## Opslag
Deze V2 gebruikt localStorage en synchroniseert nog niet tussen verschillende toestellen.
