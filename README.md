# Maaltijdplanner stabiele V1

Upload `index.html`, `styles.css`, `app.js` en `.nojekyll` naar de root van je GitHub-repository. GitHub Pages blijft ingesteld op `main` en `/(root)`.

## Belangrijkste werking
- aanvinken betekent alleen selecteren;
- geselecteerde suggesties komen bij **Klaar om in te plannen**;
- dag en maaltijd zijn vrij te kiezen;
- bevestigde suggesties komen bij **Ingeplande suggesties**;
- planning kan achteraf worden gewijzigd of losgemaakt;
- dubbele maaltijden geven een waarschuwing;
- L en A staan onder elkaar en thuis eten is groen;
- gebruikers kunnen worden gedeactiveerd en opnieuw geactiveerd;
- gegevens worden lokaal in de browser bewaard.

Deze V1 synchroniseert nog niet tussen toestellen.
